
```
dig @server name type
```


• 这里的 type 是指 DNS 查询的“记录类型”，即你希望 DNS 返回哪一类信息。

  例如：

  dig example.com A

  查询 A 记录，返回域名对应的 IPv4 地址。

  常用类型包括：

   类型     查询内容
  ━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   A        IPv4 地址
  ───────  ───────────────────────────────────────────────────
   AAAA     IPv6 地址
  ───────  ───────────────────────────────────────────────────
   CNAME    域名别名指向
  ───────  ───────────────────────────────────────────────────
   MX       邮件服务器
  ───────  ───────────────────────────────────────────────────
   NS       负责该域名的权威 DNS 服务器
  ───────  ───────────────────────────────────────────────────
   TXT      文本记录，常用于域名验证、SPF、DKIM 等
  ───────  ───────────────────────────────────────────────────
   SOA      域名区域的权威信息
  ───────  ───────────────────────────────────────────────────
   PTR      IP 地址反向解析到域名
  ───────  ───────────────────────────────────────────────────
   SRV      服务的主机和端口信息
  ───────  ───────────────────────────────────────────────────
   ANY      请求多种记录，但很多 DNS 服务会限制或拒绝此类查询

  如果省略 type：

  dig example.com

  dig 默认查询 A 记录。
